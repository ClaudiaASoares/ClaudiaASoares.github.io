# P3 SEO implementation

13 October 2026. Both P3 audit items are implemented.

## Icons and sharing metadata

The website has a CS favicon supplied as SVG, ICO and PNG. The four missing favicon URLs now have files. The head references an Apple touch icon, a Safari pinned-tab icon and a manifest naming Cláudia Soares. The manifest's two icon files exist. The obsolete theme icon references were replaced with the maintained set. PNG and ICO files were exported from the SVG source in `images/favicon.svg`.

The existing portrait supplies the default Open Graph and Twitter sharing image. Page header images and overlay images retain precedence. The shared include emits the image URL, alternative text, title, description, canonical page URL and Open Graph locale `en_US`. The default portrait has its verified dimensions, 315 by 401 pixels. Ordinary pages use `og:type=website`; publications use `article`. The sharing image setting no longer creates an Organization entity for this personal website. The homepage retains its ProfilePage and Person identity.

Both standalone lecture pages use the shared sharing metadata and icon includes. All 70 HTML pages in the XML sitemap have the required sharing properties. These checks establish the published metadata and asset responses. Preview caches on social platforms were not inspected.

## Course dates and content headings

Teaching pages and their archive omit Jekyll's default year 1900 when no date is supplied. No year was inferred from a course filename. A supplied date continues to display its year. The shared single-page layout also omits the default date from its datePublished metadata.

The CV, group and prospective-student pages each have one H1 for the page title. Their section headings use H2; group member categories use H3. The CV supervision section links to the group page in place of `TBD`. The group introduction states its existing NOVA affiliation and research focus in trustworthy machine learning for healthcare and space. Member records were preserved.
